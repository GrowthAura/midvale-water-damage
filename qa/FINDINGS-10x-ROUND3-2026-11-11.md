Mechanism (fresh evidence): SSR HTML is INTACT — H1 present in source (e.g. `<h1>Emergency Water Extraction in Midvale, UT</h1>`). On hydration, React requests the page chunk at the ROOT, unprefixed — `/_next/static/chunks/app/%5Bslug%5D/page-5ab7919444d9be38.js` → 404 / ERR_ABORTED — then `ChunkLoadError: Loading chunk 42 failed` + `Minified React error #423`. Screenshot: `shots/emergency-water-extraction-desktop-top.png` — white page, one line: "Application error: a client-side exception has occurred (see the browser console for more information)."
Sweep totals (84 visits, 21 pages x 4 viewports): **420 console errors, 286 failed requests, 80 pageerrors** — all of it P1a + the homepage's unprefixed chunk/RSC 404s (see P1b).
Root cause unchanged: `next.config.mjs` has NO assetPrefix/basePath. Fix: assetPrefix/basePath = `/midvale-water-damage/`, re-export, re-push, fresh live QA. His word + token still outstanding (one-tap option sent 2026-11-11 ~18:40, unanswered; token in-window until ~Nov 13/14).
