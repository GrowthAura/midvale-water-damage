# Midvale UT — List Re-classification REFINEMENT Report (consecutive-run rule)

Script: `qa/rebuild-lists-refine.py` — refines `qa/rebuild-lists.py`, which classified 129 of 152 list groups and left 23 flat `{type:'p'}` because an item's text recurs elsewhere in the doc and matched export lines of more than one kind or in more than one place (see `qa/rebuild-lists-report.md` §7). ## Method (consecutive-run rule, exact, no exceptions)

- The 23 target groups are `qa/rebuild-lists-report.md` §3 (group numbers + tabs). They were re-derived from `qa/r3-full-doc/doc-full.json` exactly the way `qa/rebuild-parser.py` formed them: maximal runs of consecutive bullet paragraphs sharing one `listId`, starting after each tab's intro / buttons / trust lines. Derived: **152 groups / 862 items**, per-tab counts identical to parse-report §5 — the inventory matches Appendix A, and the target set verified against the derivation as exactly 23 groups (same group number, same tab, same listId, same item order). On a fresh (unrefined) file the groups sitting flat in `pages-data.json` were confirmed to be exactly these 23 — no more, no fewer.
- Export lines: every line of `doc-export.txt` was parsed with the task's glyph strip — remove ONE leading `^\d+\.\s+` (numbered) or `^[*•\-]\s+` (bulleted). Glyph lines found: **237 numbered + 629 bulleted = 866** over 3399 export lines (identical census to `rebuild-lists.py`, whose at-most-one-space strip matches the same lines — 0 lines differ).
- For each target group, the script searched the whole export for a CONSECUTIVE run of lines whose glyph-stripped texts equal the group's item texts IN ORDER, one line per item, exact character-for-character (no fuzzy matching, no trimming of inner whitespace). ALL such runs in the whole export were collected.
- Classify `ol` ONLY if at least one run exists AND every run found is entirely numbered. Classify `ul` ONLY if at least one run exists AND every run found is entirely bulleted. In every other case (zero runs, or runs of both kinds) the group STAYS flat `{type:'p'}`.
- A classified group has its run of `{type:'p'}` blocks replaced by ONE block `{type:'ol'|'ul', items:[{segments:[...]}...]}` preserving item order and every segment (bold flags included) exactly. No word was changed. The 129 previously classified groups were not touched, and no h2/h3/table/faq block, meta, h1, intro, eyebrow, trustChips or `counts.words` was touched.
